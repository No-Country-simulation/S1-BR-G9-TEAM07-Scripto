# 🤖 Módulo de Inteligência Artificial

## Descrição

Esta pasta reúne os componentes responsáveis pelo desenvolvimento do módulo de Inteligência Artificial do projeto SCRIPTO.

Aqui estão organizadas as diferentes versões do pipeline de IA, permitindo acompanhar a evolução das soluções desenvolvidas durante o Hackathon.

---

## Estrutura

### 📁 modulo_ia_v1

Primeira versão do módulo de IA.

Contém os experimentos iniciais realizados para validação do fluxo de processamento e classificação automática de conteúdos técnicos.

### 📁 modulo_ia_v2

Segunda versão do módulo de IA.

Apresenta melhorias na organização do código, preparação dos dados, estrutura dos notebooks e evolução do pipeline de Inteligência Artificial.

---

## Objetivos

- Organizar os notebooks e experimentos de IA;
- Documentar a evolução das versões do módulo;
- Facilitar a manutenção do projeto;
- Centralizar os artefatos relacionados à Inteligência Artificial;
- Apoiar o desenvolvimento do classificador do projeto SCRIPTO.

---

## Tecnologias

- Python
- Pandas
- NumPy
- Scikit-learn
- Sentence Transformers
- Jupyter Notebook

---

## Projeto

Desenvolvido durante o **Hackathon ONE – Oracle Next Education (Alura + Oracle)** para o projeto **SCRIPTO**, uma plataforma inteligente para organização e classificação automática de conteúdos técnicos.
